Bienvenu sur le projet Horizon-App

Horizon est une application de productivité moderne conçue avec Next.js et Tailwind CSS (et différentes dépendances).

Fonctionnalités Clés de ce projet :

Authentification & Cloud : Connexion sécurisée via Firebase Auth avec synchronisation en temps réel sur Firestore.

Architecture Projets/Groupes : Organisation hiérarchique permettant de créer plusieurs projets contenant chacun leurs propres colonnes (groupes) et notes (pages).

Expérience Drag & Drop : Interface intuitive utilisant dnd-kit pour réorganiser vos tâches et idées d'un simple geste.

Éditeur de Mémos : Système de prise de notes intégré avec sauvegarde automatique et gestion d'état centralisée.

Sécurité des Données : Système de Corbeille (pages et groupes) avec restauration.
